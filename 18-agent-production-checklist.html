LangSmith vs Langfuse ​

LangSmithLangfuse
与 LangChain原生、零代码 trace需 Callback Handler
Dataset/Eval强支持
自托管云服务为主可自托管
适合LC/LG 全家桶多框架、要私有化

实践： LangChain/LangGraph 项目优先 LangSmith；已有 Langfuse 可接其 JS SDK 作 Handler，概念与 Callback 相同。
