LangGraph.js 从入门到深入 ​

独立于 Agent 系列 16 篇实战概览：这里按 LangGraph.js 官方图 API 深挖。代码以 LangGraph.js Docs 与 API Reference 为准，不编造未文档化的 API。

这套系列学什么 ​

LangGraph.js 在 LangChain 的 Message / Model / Tool 之上，提供 有状态图编排：

  • 把 Agent 每一步变成 节点
  • 用 边 表达固定跳转或条件分支
  • 用 Checkpoint 持久化 State，支持断点续跑与人机协同

本系列适合：

  • 08 的 for 循环 里 if 越来越多
  • 12 Multi-Agent 概念已读，需要 API 级落地
  • 要在 Next.js 里接 streamEvents 做 Chatbot UI

前置： 建议先读 LangChain 01 Runnable 与 02 Chat Models。
